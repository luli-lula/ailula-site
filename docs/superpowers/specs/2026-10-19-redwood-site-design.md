# ailula.top 重做：一棵红杉 · 设计文档

日期：2026-10-19 · 作者：lula（与 Claude 共同讨论）

## 1. 为什么做

lula 原来的网站 ailula.top 是 Hugo + PaperMod 搭的博客。现在需要一个**发一个链接就能让人了解"我是谁"**的网站，用在两个场合：

- **找工作**：互联网产品相关、能帮到人的工作（主要面向北美雇主，也可能有中文读者）
- **申请学校**：方向可能是植物或生态（尚未确定）

lula 的背景：在国内大厂做了 6 年产品经理（策略产品方向），2024 年主动离开；之后用 AI 自学开发，做独立产品（CELPIP12、ADHDFocus、Floating Thoughts、本土植物卡片等）；现住在纽约州乡下，是 Cornell Master Gardener 学员；喜欢红杉、森林和电影。

网站的核心表达是：**耐心地，长成一棵大树。** 红杉长得慢，但能活两千年、长到一百多米。

## 2. 目标 / 非目标 / 反目标

**目标**
- 30 秒之内，访问者能记住"这是谁"，也能找到简历和项目
- 网站本身就是一个作品：动画有质感，画面有真实感，能体现 lula 的产品能力和审美
- 三类内容都能呈现：经历、项目、思想（写作），再加上电影和书
- 中英双语
- 可以长期维护：之后加文章、加项目、改"此刻"卡片都很容易

**非目标**
- 不做 CMS、评论、会员、后台
- 不做通用博客引擎的全部功能（标签云、分页归档等），够用就行
- 这一期不做 iOS 或 App

**反目标（即使能运行也算失败）**
- 招聘官找不到简历或联系方式，或者要等很久的加载
- 画面像卡通或模板，没有真实感
- 植物学上出错，比如把不是红杉林的植物放进来（lula 是 Master Gardener，懂行的人一眼就能看出来）
- 手机上卡顿、发热，或者直接打不开

## 3. 已经定下来的设计

### 3.1 整体结构：一个森林世界

| 位置 | 内容 | 隐喻 |
|---|---|---|
| 首页 · 林底（0m） | 名字、slogan、一句话介绍、入口 | 清晨的林底，仰望一棵消失在雾里的红杉 |
| 首页 · 树干（0–115m） | 时间线：经历、项目、文章 | **高度 = 时间**，从 2017 年到现在 |
| 首页 · 树冠（115m） | "此刻"卡片、联系方式、简历 PDF | 穿出雾层，看到阳光和云海 |
| 林下（写作页） | 全部文章 | 红杉脚下的森林地面，横向沿小路走 |
| 树洞（电影和书） | 个人十佳 + 海报墙 | 被火烧出来的树洞（goose pen），藏着一间小放映室 |
| 项目详情页 | 每个项目的案例 | 从树枝点进去 |

### 3.2 首页：爬一棵红杉

- **林底（0m）**：清晨，有雾，有光束，地上有剑蕨，巨大的树干越往上越细，最后消失在雾中。中间是 `lula` 和 slogan「耐心地，长成一棵大树」（英文版写法见第 5 节），下面一句话介绍。底部三个入口：↑ 爬树（经历和项目）、↓ 林下（写作）、Lo-fi 版。彩蛋：一只小狗从画面里走过。
- **往上爬**：页面往下滚动，镜头沿着树干往上移动。左边有高度表（0m · 2017 → 115m · 现在）。树枝挂在对应年份的高度上，挂的卡片分三类，样式不同：经历、项目（带截图）、文章（小标签）。
- **年轮指南针**：放在右下角，是一个不规则、带木纹的真实红杉横截面。每往上爬一年就多长一圈，当前年份用红线标出。变化大的年份圈更宽（2024、2025）。点某一圈，镜头会滑到那一年的高度。
- **树冠（115m）**：穿出雾层，阳光照着云海，远处几棵树冠露出来。这里有"此刻"卡片（每月更新：正在做什么、在找什么）和联系区：Email、GitHub、X、下载简历 PDF。

### 3.3 林下：写作花园

- 从首页底部或导航进入，场景是森林地面，横向滚动，沿着一条小路走
- **每类文章对应一种真实的红杉林下植物**：
  - 产品思考长文：一圈红杉幼树（fairy ring）
  - 读书和观影笔记：剑蕨（sword fern）
  - 生活周记：红杉酢浆草（redwood sorrel）和蘑菇
  - 2017 年的产品课旧笔记：长满苔藓的倒木（nurse log），上面冒着新芽
- **文章会长大**：每篇文章有一个成熟度（幼苗、长开、成材），对应不同大小的植物
- 鼠标悬停显示标题和日期，点击进入干净的阅读页
- 顶部有话题筛选，还有"列表看全部 · 搜索"

### 3.4 树洞：电影和书

- 红杉底部被山火烧出的大树洞，里面是一间温暖的小放映室
- **个人十佳**：一份由 lula 亲自挑选的**固定清单**（目前空缺，待 lula 补充）
- **海报墙**：五星电影，数据来自现有的 `luli-lula/douban-data` 仓库（约 300 张海报，带短评，通过 jsDelivr 提供）
- 书的部分也放在树洞里，形式与电影相同（数据同样来自 douban-data）

### 3.5 项目详情页

- 每个项目一页，结构是：为什么做 → 怎么做 → 结果和数据 → 学到了什么 → 链接
- 已知项目：CELPIP12、ADHDFocus、Floating Thoughts、本土植物卡片（Wild Ones）。其他项目待 lula 确认
- 现有内容先从旧网站迁移，缺的部分留空，标为「待补充」

### 3.6 Hi-Fi 与 Lo-Fi 两种模式（参考 felixrieseberg.com）

- **Hi-Fi**：完整的动画和场景体验
- **Lo-Fi**：同样的内容，用简洁的排版呈现（简历式首页 + 项目列表 + 文章列表 + 电影列表），加载很快，不需要任何 3D 或动画
- 每个页面都有切换按钮，选择记在浏览器里
- **自动切到 Lo-Fi 的情况**：浏览器设置了"减少动态效果"、检测不到 WebGL、设备性能弱。页面上会提示"已为你切换到 Lo-Fi，点这里试试 Hi-Fi"（做法和 Felix 一样）
- Lo-Fi 也是给搜索引擎和打印用的版本

### 3.7 中英双语

- 全站中英双语，每一页、每张卡片、每个按钮都有两种语言，导航栏有切换开关
- 文章允许只有一种语言：没有翻译的文章显示原文，并注明"仅中文"或"English only"
- 旧网站的链接（`/zh/posts/...`、`/posts/...`、`/projects/...`）都要重定向到新地址，不能失效

### 3.8 内容空缺的处理

- lula 明确说过：做的过程中缺的信息就留空，之后一起补
- 页面上用明显的占位符显示「待补充 / TODO」，**不能编造内容**（尤其是项目数据、经历细节、十佳片单）
- 维护一个 `CONTENT-TODO.md`，列出所有待补充的位置

## 4. 约束

- **真实感和动画是最难、也最重要的部分**（lula 原话）。所以第一步先做一个"真实感试验"（见第 6 节），lula 看过、认可之后，再铺开做后面的部分
- 域名继续用 ailula.top。在新网站被 lula 认可之前，旧网站不能下线
- 旧网站的仓库在 `~/Documents/Side-Projects/luli-lula.github.io`，文章是 Markdown，带 `.zh.md`、`.en.md` 后缀，可以直接迁移
- 保留现有的 Google Analytics（G-WMC06JHFDG）
- 手机上必须能用：Hi-Fi 至少在近两年的 iPhone 上流畅，否则自动切到 Lo-Fi
- 所有素材（纹理、模型、字体）必须可以商用或是 CC0，并记录来源

## 5. 已决定的"怎么做"，以及谁做的决定

**lula 决定的**
- 不再使用 Hexo 或 Hugo，从零开始做
- 森林世界的整体结构（第 3 节全部）
- 两种模式（Hi-Fi / Lo-Fi）、中英双语
- 个人十佳是固定清单
- slogan 的意思是"耐心地长成一棵大树"
- 内容缺的地方留空，之后一起补

- **真实感走照片风格**：真实的树皮纹理、真实的光线和雾，不走绘画或插画风。素材优先用照片扫描类的 PBR 纹理、HDRI 天空，蕨类和枝叶用照片贴图

**Claude 的判断（lula 可以推翻）**
- **框架**：Astro + TypeScript。文章、项目、电影都用内容集合（Markdown 和 JSON）管理，3D 和动画只作为局部组件加载，Lo-Fi 页面是纯静态 HTML
- **首页 Hi-Fi 场景**：用 Three.js 做真 3D，原因是雾、光束和景深是真实感的关键，2D 很难做到。具体做法：
  - 树干程序化生成（锥形、凹凸起伏），贴 Poly Haven 的 CC0 树皮 PBR 材质
  - 雾、体积光（后处理），远处有更多树干
  - 枝叶用实例化渲染
  - 镜头高度跟着滚动走（Lenis 平滑滚动 + GSAP ScrollTrigger）
  - 卡片是 HTML，叠在 3D 画面上，位置跟随树枝的 3D 坐标
- **林下和树洞**：先用分层 2.5D 实现（SVG 和 Canvas，做视差和光影），植物程序化生成。如果真实感试验证明 3D 值得做，再升级
- **年轮指南针**：程序化生成的 SVG（讨论阶段已经有原型）
- **默认语言是英文**，中文放在 `/zh/`。理由是主要读者是北美的雇主和学校
- **英文 slogan 暂定为** "Growing slowly, like a redwood."
- **部署**：先部署到 Vercel 的预览地址给 lula 看，确认后再把 ailula.top 切过去
- **项目位置**：新仓库放在 `~/Documents/Side-Projects/ailula-site`
- **英文版的电影墙**：douban-data 的片名和短评都只有中文（2591 部电影，301 部五星，其中 150 部有短评）。英文版先直接显示中文，并标注"Chinese only"，规则和文章一致；有英文原名的电影另外显示原名。个人十佳由 lula 亲自写中英两份
- **书的范围**：五星书只有 15 本，数量太少，所以书墙放宽到四星及以上
- **海报和封面的版权**：第 4 节"只能用商用或 CC0 素材"的规则只适用于设计素材（纹理、模型、字体）。海报和书封属于个人评论性质的展示，可以用，数据继续从 douban-data 取
- **旧链接的重定向范围**：根据旧网站生成的 sitemap 整理，包括文章、项目、`/movies/`、`/books/`、`/tags/`、`/archives/`，以及 RSS（`index.xml`，新站继续提供 RSS）
- **项目页的起点**：旧网站只有 CELPIP12 和 ADHDFocus 两个项目页可以迁移。Floating Thoughts 和本土植物卡片从零开始写，内容先留空

## 6. 做的顺序（里程碑）

1. **真实感试验**：只做首页的 3D 爬树。从林底爬到树冠，包含雾、光束、树皮、几根树枝和占位卡片，以及年轮指南针。**lula 看过、认可之后才继续**
2. 框架骨架：Astro、中英双语路由、Hi-Fi / Lo-Fi 切换、Lo-Fi 版本的全部页面、旧文章迁移、旧链接重定向
3. 首页完整版：时间线数据接上、所有卡片、树冠的"此刻"卡片和联系区
4. 林下写作页
5. 树洞电影和书
6. 项目详情页（内容留空）
7. 和 lula 一起补内容，然后上线，切换域名
