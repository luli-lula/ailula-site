论文审阅与参考文献核查：上传一篇 ML 论文，抽出每个论断，到文献里找到出处并核对每一条引用。

基于 FactReview 论文（Yue et al., 2026, [arXiv:2604.04074](https://arxiv.org/abs/2604.04074)）。

我负责产品化：论文原来只有一个 GitHub 仓库，我把它做成可以直接打开使用的网站，并加上用户反馈，比如标出不准确的结果，再用这些反馈反过来改进它。
