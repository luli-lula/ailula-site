# 内容整理计划

做网站的同时，也是把每个项目整理一遍：讲清楚它是什么，记下还剩什么要做。

## 怎么做

1. 一次讲一个。lula 口述（打字或语音转文字都行），不用整理。
2. Claude 写成中英文，放进 `src/content/projects/<项目>/`，在本地 `pnpm dev` 里看。
3. lula 看过，改到满意，再做下一个。
4. 每讲完一个，把"还剩什么要做"记在下面的表里。

每个项目都问这 5 个问题：

1. 为什么做？是什么事让你想做它？
2. 给谁用？现在谁在用（包括你自己）？
3. 怎么做的？你负责哪部分，用了什么工具？最难的一个决定是什么？
4. 现在做到哪一步？有没有数字（用户数、收集的植物数、反馈）？
5. 学到了什么？下一步做什么？
